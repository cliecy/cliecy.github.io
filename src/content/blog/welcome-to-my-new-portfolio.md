This site is a complete revamp of my previous work. I wanted to create something that stands out, something that feels "alive".

## Tech Stack

- **React**: The core framework.
- **Three.js / React Three Fiber**: For the 3D elements you see in the background.
- **Framer Motion**: For the smooth page transitions and animations.

## Why 3D?

The web is moving towards more immersive experiences. 3D allows for a depth of interaction that flat design simply cannot match.
